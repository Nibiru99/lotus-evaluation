# Three Lotus evaluation samples

These reduced numerical samples come from actual saved findings: Probability Transport (#62), 64-bit Word/Subtraction (#64), and Travelling Wave (#66). They retain angular boundary coefficients and one outer density slice. They exclude the complete recursive/growth state, private runtime and FIEND. Their finite sampled geometry is intentionally inspectable if this exact payload is approved.

Run `python check_samples.py --out ../crystal-sample-check.json` using Python's standard library. The checker independently tests probability mass and a diffusion step, the saved wave harmonic and a phase step, and the stored word's exact Gray-channel readout. Results are written to a fresh file.

These are numerical sample checks, not a replacement for executing a crystal through the full Lotus socket. Probability/wave field response differs from their issued boundary; the checker reports that gap. The word sample retains its saved fixed word, not an unexecuted changing-operand benchmark. Live compiled GPU timing is a separate benchmark in the Lotus companion. No expiry, infinite durability, new noise ceiling or crystal-derived speedup is claimed here.
