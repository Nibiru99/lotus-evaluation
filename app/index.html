Hardware inventory & installation requirements

Reading local hardware…

Use the vendor tools already installed on your machine. Lotus does not install drivers or change hardware settings. The CPU checks, CUDA workload and optional energy capture have separate requirements.

  • NVIDIA: compatible driver and the CUDA runtime/packages required by the selected test. Inventory uses the driver's nvidia-smi tool. Official CUDA installation guide · NVIDIA telemetry reference
  • AMD CPU energy/profiling: optional AMD uProf, subject to processor and OS support. Installing it does not enable AMD GPU execution. Official AMD uProf downloads
  • AMD GPU: graphics detection is separate from compute support; a ROCm/HIP adapter still needs implementation and validation. AMD SMI prerequisites

Official setup links open in your browser only when selected. Lotus does not download or install these tools.
